# 🧍 Posture Recognition

An AI-based Posture Recognition System using Computer Vision to analyze and identify human posture in real time.

## 🚀 Live Demo

[View Live Demo](https://prakashrajput0412.github.io/Posture-Recognition/)

## 📌 About the Project

Posture Recognition is a computer vision-based project developed to detect and analyze a person's posture through a camera-based interface.

The system processes visual input and provides posture-related feedback through an interactive web interface.

## ✨ Features

- Real-time posture recognition
- Computer vision-based analysis
- Interactive web interface
- Visual posture indicators
- Responsive interface
- Live browser-based demonstration

## 🛠️ Technologies Used

- HTML

- Computer Vision
- AI-based posture analysis
